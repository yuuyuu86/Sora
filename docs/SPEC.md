# Sora 仕様書

## 1. アプリ概要
Soraは、現在地の天気と時間に合わせて、Macのデスクトップに自然の風景と天候を映し出すアプリです。

専用の風景を背景に、雨や雪、日差しなどが変化します。雪はアプリのウィンドウやDockに積もり、カーソルで払うことができます。

実写に近い風景と自然な動きを基本としながら、触れたときの反応には少しだけデフォルメを加えます。

## 2. 対象環境
- 対応OS：macOS
- 利用形態：デスクトップ上で常時利用
- 操作入口：メニューバーを想定

## 3. 基本体験
起動すると、専用の風景がデスクトップ背景に表示されます。風景は現在地の天気と時刻に合わせて変化し、太陽や月がうっすらと現れます。

天候の演出は背景だけでなく、アプリのウィンドウやDockにも広がります。例えば、降り積もった雪をカーソルで払うと、雪が崩れて下のウィンドウに落ちる体験を目指します。

普段は控えめで作業を妨げず、触れると自然が反応することを重視します。

## 4. 風景
### 初期の風景：草原
初期の風景には、空を広く見せた実写に近い草原を採用します。画面の手前には草を配置し、風によってゆっくり揺らします。
- 雲が空をゆっくり流れる
- 天気に合わせて空や遠景の見え方が変化する
- 雨の日は遠くの景色が少しかすむ
- 雪の日は草原も白くなる
- 時間に合わせて光の色や向きが変わる

背景は将来、草原以外の風景にも変更できるようにします。追加する風景の種類や提供時期は未定です。

## 5. 天気の演出
最初のバージョンから、一通りの天気を表現します。

| 天気 | 表現 |
|---|---|
| 晴れ | 柔らかな日差し。太陽と光の変化が見える |
| 曇り | 雲が広がり、光が弱まる。雲の影がゆっくり流れる |
| 雨 | 雨粒が降り、ウィンドウやDockに当たって小さく跳ねる |
| 雪 | 雪が降り、ウィンドウやDockに少しずつ積もる |
| 霧 | 遠景や画面の端がうっすらかすむ |
| 雷 | 空がときどき光り、周囲にも一瞬光が広がる |

風は独立した天気だけでなく、雨や雪などと組み合わせる要素として扱います。風向きや強さに応じて、雨・雪・雲・草などの動きが変わります。

### 天気の切り替え
- 基本は現在地の天気に連動する
- 好きな天気を手動でも選べる
- 天気が変わる際は、急に切り替えず、雲や降水量などを徐々に変化させる

## 6. 時間と光の変化
現在地の日の出・日の入りと時刻に合わせて、太陽や月、風景の明るさや色を変化させます。

| 時間帯 | 表現 |
|---|---|
| 朝 | 低い位置に淡い太陽。柔らかく暖かい光 |
| 昼 | 高い位置に太陽。明るく自然な光 |
| 夕方 | 沈む太陽と、薄いオレンジ色の光 |
| 夜 | 淡い月と、少し青みのある柔らかな光 |

- 太陽と月は画面の端にうっすら表示する
- 雲が多いときは、太陽や月がぼんやり隠れる
- 明るさや色はアプリの演出として表現する
- Mac本体の画面の明るさは変更しない

## 7. ウィンドウ・Dockとの相互作用
雨や雪は、画面上にあるウィンドウやDockに反応します。

### 雨
- ウィンドウの上端やDockに当たると、小さく跳ねる
- 雨が強いときは、水滴がまとまって端から落ちることがある

### 雪
- ウィンドウの上端やDockに少しずつ積もる
- 上のウィンドウから落ちた雪が、下のウィンドウに積もる
- ウィンドウを動かすと、積もった雪が揺れたり崩れたりする
- ウィンドウを閉じたときは、積もっていた雪が舞い落ちる

自然な動きを目指しますが、雪の崩れ方などは、見ていて気持ちよく感じられるよう少し強調します。

## 8. カーソルとの相互作用
特別な操作をしなくても、カーソルを動かすだけで天気に触れられるようにします。
- 雪に触れると、積もった雪を払える
- ゆっくり動かすと雪が少し崩れ、素早く動かすと大きく舞う
- 雨粒もカーソルに対して控えめに反応する
- 霧はカーソルの通り道が少し晴れる

通常のクリックやウィンドウ操作を妨げないことを前提とします。

## 9. 設定
メニューバーから、次の項目を操作できることを想定します。
- 現在の天気の確認
- 天気の自動連動・手動選択
- 現在地の利用・場所の手動選択
- 演出全体の強さ
- 太陽・月の表示オン／オフ
- 光や色の変化の強さ
- 音のオン／オフ
- 背景の選択

## 10. デザイン方針
- 風景は実写に近い見た目にする
- 光、色、天気の動きは自然で控えめにする
- カーソルに対する反応は、少しだけ分かりやすく、気持ちよくする
- デスクトップ上の文字やアプリの操作を邪魔しない
- 作業中も使いやすいよう、演出の強さを調整できるようにする

## 11. 技術検証が必要な項目
以下は実現を目指す仕様ですが、macOSの仕組みや必要な権限を含め、試作で確認します。
- 専用の風景をデスクトップ背景として動かせるか
- 他のアプリのウィンドウやDockの位置・重なりを取得できるか
- ウィンドウやDockの上に、雨や雪を自然に表示できるか
- 通常のクリック操作を妨げずに、カーソルの動きへ反応できるか
- 常時表示したときのCPU・GPU・バッテリー消費を実用的に抑えられるか

## 付録：実装メモ（v0.1）
| 検証項目 | 実装方式 |
|---|---|
| 背景として動かす | デスクトップレベル（アイコンより下）の透過しないウィンドウを各画面に配置し、SwiftUI Canvas で描画 |
| ウィンドウ位置・重なり | `CGWindowListCopyWindowInfo` で前面順の矩形を取得（画面収録権限は不要、位置のみ使用） |
| ウィンドウ上の雨雪 | Dockより上のレベルに、クリック透過（`ignoresMouseEvents`）の透明オーバーレイを配置 |
| カーソル反応 | `NSEvent.mouseLocation` を毎フレーム参照（権限不要、クリックは一切奪わない） |
| 消費電力 | 30fps 上限、粒子数上限、演出強度に応じて粒子数を削減 |
